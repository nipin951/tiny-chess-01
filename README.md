A chess engine in under 4 KB of Python: 0x88 board, negamax alpha-beta search with PVS, late-move reductions, quiescence search, a transposition table and tapered piece-square tables, playing on a fixed 60,000-node budget so every game is deterministic.

## Run it

```sh
python3 main.py
```
